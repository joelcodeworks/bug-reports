## Title
Language switching causes incorrect character display in the menu.

## Environment
Web application and mobile application.

## Description
The login process works correctly. However, after changing the application language, some characters in the menu are displayed incorrectly, making the menu difficult to read in the second language.

## Steps to Reproduce
1. Open the web application or mobile application.
2. Log in with valid credentials.
3. Access the main page.
4. Change the application language.
5. Observe the menu text.

## Expected Result
The application should display the menu text correctly after changing the language.

## Actual Result
After changing the language, some characters are displayed incorrectly, making the menu difficult to read.

## Severity
High

## Priority
High

## Priority Justification
High priority is assigned because the issue affects the usability of the application's interface for users who need to use the application in another language.

## Impact
Users who rely on the affected language may have difficulty reading and navigating the menu, wich negatively affects the usability of the application.

## Evidence
Not available.
