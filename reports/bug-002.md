## Title
Notifications are not correctly filtered after applying a filter.

## Environment
Web application or mobile application.

## Description
When the user applies a filter to the displayed data, the filtered information is shown correctly. However, notifications continue to be received according to the general notification settings instead of being adjusted to the applied filter.

## Steps to Reproduce

1. Open the application.
2. Log in with valid credentials.
3. Access the main view.
4. Apply one of the available filters.
5. Observe the displayed data and subsequent notifications.

## Expected Result
The application should display only the data corresponding to the selected filter, while notifications should behave according to the applied filter and the configured notification settings.

## Actual Result
The application correctly filters the displayed data, but notifications continue to be received according to the general notification settings instead of taking the applied filter into account.

## Severity
Medium

## Priority
Medium

## Priority Justification
Medium priority is assigned because the main functionality remains operational, but the notification behavior does not fully correspond to the user's selected filter.

## Impact
The issue may cause users to receive notifications that are not relevant to the filtered information they are currently viewing, which can create confusion and negatively affect the user experience.

## Evidence
Not available.
