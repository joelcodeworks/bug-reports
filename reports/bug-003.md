## Title
Projects section displays a blank page

## Environment
Web application

## Description
After logging in and navigating to the Projects section, the page does to load correctly and displays a blank page. Refreshing the page does not resolve the issue.

## Steps to Reproduce
1. Open a web browser.
2. Access the application's main page.
3. Log in with valid credentials.
4. Navigate to the Projects section.
5. Observe the page.

## Expected Result
The Projects section should load correctly and allow the user to access its available functionality, such as creating or deleting projects.

## Actual Result
The Projects section display a blank page and does not allow the user to perform any section. Refreshing page does not resolve the issue.

## Severity
High

## Priority
High

## Priority Justification
High priority is assigned because the affected section is inaccessible and prevents user from using its main functionality.

## Impact
Users cannot access the Projects section or perform actions available there, which prevents them from completing tasks that depend on this functionality.

## Evidence
Not available.
